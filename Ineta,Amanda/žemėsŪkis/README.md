# 🌾 AgroLietuva – Modernus Žemės Ūkis

Informacinis ir interaktyvus tinklalapis apie Lietuvos žemės ūkį.

## Funkcionalumas
- Pagrindinių Lietuvos žemės ūkio šakų apžvalga.
- Lietuvos žemės ūkio statistikos rodikliai.
- Interaktyvus sezoninis darbų kalendorius (Pavasaris, Vasara, Ruduo, Žiema).
- Sėklos normos ir prognozuojamo derliaus skaičiuoklė.
- Naudingų straipsnių skiltis su pilno teksto skaitymo langu.
- Kontaktų forma ir pilnas prisitaikymas prie mobiliųjų įrenginių.

## Paleidimas per GitHub Pages
1. Įkelkite visus 4 failus (`index.html`, `style.css`, `script.js`, `README.md`) į savo GitHub repozitoriją.
2. Eikite į **Settings → Pages**.
3. Skiltyje **Branch** pasirinkite `main`, aplanką `/ (root)` ir spauskite **Save**.
